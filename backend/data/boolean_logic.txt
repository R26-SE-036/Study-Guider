Topic: Boolean Logic and Comparison Operators in Java
A boolean holds exactly one of two values, true or false.
Comparison operators produce booleans: == equal to, != not equal to, < less than, > greater than, <= less than or equal, >= greater than or equal.
The logical operators are && for and, || for or, and ! for not. The expression a && b is true only when both are true, while a || b is true when at least one is.
The && and || operators short-circuit: if the left side already decides the answer, the right side is never evaluated. That is why if (arr != null && arr.length > 0) is safe and reversing the order is not.
Never write if (flag == true). Write if (flag). Comparing a boolean to true adds nothing and invites the classic slip of writing = instead of ==.
Precedence: ! binds tightest, then &&, then ||. Brackets make mixed conditions readable and are worth adding even when not required.
